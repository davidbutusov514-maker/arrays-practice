# Arrays Practice — Одномерные массивы в C#

**ФИО:** Бутусов Давид
**Номер в журнале:** 6
**Вариант итогового задания:** 0 (Успеваемость студентов)

Исходный репозиторий преподавателя: https://github.com/zayarniy/arrays-practice.git

## Выполненные задания

- **Task1.Statistics** — статистика случайного массива (сумма, произведение, чётные, больше среднего)
- **Task2.InputSort** — ввод с обработкой Format/Overflow, реверс, сортировка, поиск max/min
- **Task3.Unique** — уникальные элементы через вложенные циклы (без LINQ и HashSet)
- **Task4.Exceptions** — FormatException, OverflowException, IndexOutOfRangeException
- **Final.Task** — вариант 0: успеваемость студентов

## Запуск

```bash
dotnet run --project Task1.Statistics
dotnet run --project Task2.InputSort
dotnet run --project Task3.Unique
dotnet run --project Task4.Exceptions
dotnet run --project Final.Task
